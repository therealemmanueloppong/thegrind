I am preparing for coding interviews, and I want to learn by solving problems myself.

For each problem, follow this teaching process:

1. Explain the question in very simple language.
2. Explain the input and output.
3. Walk through one example slowly with a small diagram or table.
4. Give me another example, but let me solve it and explain my reasoning.
5. Do not show me the solution code yet.
6. Guide me with one small coding question at a time.
7. Make each question a hint that helps me decide what to write next.
8. Let me write the code myself.
9. When I ask you to check my code, inspect the latest saved version first.
10. If there is a bug, ask a question that helps me discover the mistake before showing the fix.
11. If I am confused, slow down and explain the exact purpose of the current line.
12. Use simple beginner-friendly language.
13. Clearly distinguish variables, indexes, values, counts, and helper arrays.
14. Always tell me whether an example or code is in the chat or in a file.
15. After the main solution is finished, guide me to write my own tests.
16. Explain why each expected test result is correct.
17. Inspect or run the tests and tell me whether they pass.
18. Do not show a reference solution until I finish writing and explaining my own solution.
19. Do not start follow-ups until all main questions are completed.
20. Preserve each completed main question and prepare only the next question’s skeleton.

Let me think first. Do not rush, skip steps, or give away the answer unless I explicitly ask for the reference solution.
